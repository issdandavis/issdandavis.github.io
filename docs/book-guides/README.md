# Book preview voice-guide standard

The public book previews are system documentaries, not author reels. Each guide
must give the listener a useful idea before it asks for attention, email, or a
purchase.

## Three depths

1. **Candy (30–45 seconds):** one exact idea with one honest boundary.
2. **Guided descent (3–5 minutes):** narration, authentic diagrams, transcript,
   evidence badges, and a clear next question.
3. **Little movie (6–10 minutes):** the same script expanded into a visual
   walkthrough with captions, chapter marks, reduced-motion alternatives, and
   a source/claim card at the end.

## Required passes

Every script receives three independent passes before synthesis:

- **technical keeper:** maps each claim to `INVARIANT`, `IMPLEMENTED`,
  `MEASURED`, `SUPPORTED`, `PROPOSED`, `HISTORICAL`, `REFUTED`, `DEFECT`, or
  `UNKNOWN`;
- **fresh listener:** removes unexplained names, tunes pace, and makes the first
  useful idea understandable without prior lore;
- **visual keeper:** binds every beat to an authentic diagram or a clearly
  labeled illustration and checks captions, contrast, and reduced motion.

The final editor keeps only language that survives all three passes. Model
benefit, security, and information-capacity claims never borrow certainty from
an adjacent mechanism.

## Artifact bundle

Each published guide should eventually contain:

- production script and claim matrix;
- MP3 voice guide;
- accessible on-page transcript;
- WebVTT or SRT captions;
- six-to-eight-beat storyboard;
- 16:9 film master and a short vertical cut;
- source hashes and a browser/media quality receipt.

## Series route

The first *Trits, Bits, and Bobs* sequence is:

1. One byte, many views.
2. Six states are not nine.
3. Negative space is typed state.
4. The provenance ladder: every abstraction keeps a route home.
5. A model only learns what enters the forward path.
6. Geometry supplies coordinates, not authority.
7. Proposal, decision, effect, and receipt remain separate.
8. The experiment ledger keeps failed and non-promoted runs.

The *Six Tongues Protocol* preview can reuse the same guides as a bridge from a
story scene into the system it remembers. Fictional framing is optional;
technical meaning is the authority.
