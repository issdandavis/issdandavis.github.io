Option A: Python (recommended)

python benchmark.py --target "https://your-api-base/v1" --key "your-api-key" --model "your-model"
# Report saved to benchmark_report.json

Option B: Colab (no install)

Open the included Colab notebook, upload the kit zip, paste your API key, and click Run All.

The CSV has the same 251 prompts. Send them however you want and score the replies with RUBRIC.md. Only test a system you operate or have permission to test.
