What can be handed to someone today, and what still needs a thing to ship

Posters now. A USB when it can be mailed.

The notes are the public argument. A poster is the same argument in one picture, so it can travel on X and land back on the note. A kit is the files a person can run. A physical object waits until there is a way to pack it and a price for that packing.

Free to print

Each card is 1200 by 630. Save it, print it, or attach it to a post. The post should use the address on the card, so the picture and the note stay the same claim.

  • The pad does not land where you drew it — the note
  • The radiator is half the engine — the note

The stronger post for a technical reader is the pad card. The stronger post for anyone else is the radiator card. Both return to a page that says what was checked and what was not measured here.

The coding kit that exists

The kit is the download shop. Six zips are already there, and the smallest is $5. They are files you run on your own machine: a benchmark you can score, a decision record, a role packet, a content spin, an n8n check, and a small training starter. Buying them is the kit. A second checkout that bundles the same files under a new name would be a second price for the same bytes.

A USB of those files

A USB would carry the same zips, so someone can plug it in without a download. That object is not in the shop. There is no shipper, no stock, and no separate price. When those three exist, the USB can be a product. Until then the honest version is the download.

A stylus that speaks

A pen with a microphone, a small model, and a speaker is a real product shape: you talk, it answers, and the answer stays on the device or on a phone paired to it. This site does not have that device. There is no buy button for it. The writing pass is the speaking-and-drafting help that exists today, and it is a person reading sentences, not a pen.
