How this website is addressed · checked 24 October 2026

One site, several doors

aethermoore.com is one website. GitHub Pages publishes it from one repository, and that service keeps one custom domain on the site. The domain file in the repository is aethermoore.com. HTTPS is on. The live Pages record names that same domain.

Different work already has a different address. A path is the door. You can send someone the short path, and the folder page sends them to the real page.

DoorAddressWhat opens
Lab aethermoore.com The homepage.
Writing /writing/ The sentence pass and the three books. The page itself is /services.html. The older /hire/ door opens the same pass.
Downloads /downloads/ Six software zips. The shop starts at $5. The page itself is /shop.html.
Notes /notes/ The research shelf, including the hybrid-bonding note and the harvester note. The section is /research/.
Books /books.html The three books. Amazon is where the sale happens.

A second domain

Another domain name does not become a second copy of this site by sitting in the repository. GitHub Pages will not attach a second custom domain beside aethermoore.com on this project. The name you already own can still open one of these doors. At the registrar, or at whatever DNS host already controls that name, you forward the name to one full address:

  • A writing name forwards to https://aethermoore.com/writing/
  • A shop name forwards to https://aethermoore.com/downloads/
  • A notes name forwards to https://aethermoore.com/notes/

The forward is a setting on the name, after the name already points somewhere you control. This page does not register a domain, and it does not change DNS. When you want a name attached, the two facts needed are the domain and which door it should open.
