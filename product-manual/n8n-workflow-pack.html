First-run path

1. Import one workflowDo not import the entire bundle blindly on the first pass.
2. Leave credentials emptyThis workflow does not use an API key. Activate it only when you want the webhook live.
3. Inspect external nodesCheck any API, webhook, or connector steps before running.
4. Run a safe testUse test data or a non-production route first.
5. Save the working versionExport or snapshot the first known-good state.

Success check

  1. SCBE_Decision_Check.workflow.json imports.
  2. A valid ALLOW, QUARANTINE, or DENY body with a rationale returns HTTP 200.
  3. A body without those fields returns HTTP 400.
  4. The workflow stays inactive until you choose to turn the webhook on.

Do not do this

Do not point every workflow at live production systems before you have one safe successful run and a rollback path.
